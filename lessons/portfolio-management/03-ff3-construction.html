1. 目標與資料

第 01 講介紹了 FF3 模型的「長相」，這一講要真的把它做出來：從個股資料出發，一步步建構出規模因子 SMB 與價值因子 HML，最後和 Fama-French 官方公布的因子比較，確認做得對不對。

表 3.1　需要的資料欄位
欄位來源意義
PERMNOCRSP股票的永久代碼（不會因改名或換代號而改變）
dateCRSP月底日期
EXCHCDCRSP交易所代碼：1 = NYSE、2 = AMEX、3 = NASDAQ
SHRCDCRSP股票類型代碼：10、11 = 普通股（排除 ETF、REITs、ADR 等）
PRC、SHROUTCRSP月底股價、流通在外股數
RETCRSP月報酬（含股利）
BMCompustat 計算帳面市值比

兩個排序變數的定義：

MEi,t = |PRCi,t| × SHROUTi,t 式 (3.1)　市值（market equity）
BMi,t = Book equityi,tMEi,t 式 (3.2)　帳面市值比（book-to-market ratio）
補充：為什麼股價要取絕對值？

CRSP 中，若某股票當天沒有收盤成交，會用買價與賣價的平均值代替收盤價，並加上負號作為標記。所以計算市值時要先取絕對值，否則會算出負的市值。

2. 時間點：什麼時候排序、用哪個時點的資料？

因子建構最容易出錯的地方不是公式，而是時間點。Fama-French 的慣例如下：

  1. 每年 6 月底排序一次：規模用 t 年 6 月底的 ME；價值用 t−1 會計年度的帳面權益，除以 t−1 年 12 月底的 ME。
  2. 持有 12 個月：分組結果從 t 年 7 月沿用到 t+1 年 6 月，然後重新排序。
  3. 市值加權用上個月底的 ME：第 t 月的權重只能用第 t−1 月底已知的市值。
常見錯誤：前視偏誤（look-ahead bias）

如果用 t−1 年 12 月的財報資料在 t−1 年 12 月就排序，等於假設投資人當下就看得到財報，但年報通常要幾個月後才公布。等到 6 月底，可以合理確定前一年的財報都已公開。同理，計算第 t 月報酬時，權重和分組都必須是「第 t 月開始前」就已知的資訊，程式中對應的就是 shift(1)。

3. 用 NYSE 股票決定分界點

分界點只用 NYSE 股票計算，但所有普通股（NYSE、AMEX、NASDAQ）都會被分進組合：

  • 規模：NYSE 股票 6 月底 ME 的中位數。ME ≤ 中位數為小型股（S），大於為大型股（B）。
  • 價值：NYSE 股票 BM 的第 30 與第 70 百分位數。低於第 30 百分位為成長股（G），30～70 為中性（N），高於第 70 百分位為價值股（V）。BM 為負或缺值的股票不納入。

為什麼不用全部股票算分界點？NASDAQ 和 AMEX 有大量市值極小的微型股（microcaps）。如果用全部股票的中位數，分界點會被拉得很低，「大型股」組合裡會混進許多其實很小的公司，「小型股」組合則幾乎全是微型股。用 NYSE 分界點，可以讓兩組在經濟意義上更有代表性，也避免因子報酬被流動性差的微型股主導。

4. 2×3 排序與六個投資組合

規模排序與價值排序各自獨立進行（非條件排序），兩者交集形成六個投資組合。每個組合內部都用市值加權計算月報酬：

表 3.2　ME × BM 的六個投資組合
成長 G（BM < P30）中性 N（P30～P70）價值 V（BM > P70）
小 S（ME ≤ P50）SGSNSV
大 B（ME > P50）BGBNBV
Rp,t = ∑i∈p MEi,t−1 Ri,t∑i∈p MEi,t−1，　p ∈ {SG, SN, SV, BG, BN, BV} 式 (3.3)　各組合的市值加權報酬

5. 由六個組合組出 SMB 與 HML

RSMB = RSG + RSN + RSV3 − RBG + RBN + RBV3 式 (3.4)　規模因子（small minus big）
RHML = RSV + RBV2 − RSG + RBG2 式 (3.5)　價值因子（high minus low）

注意設計的巧思：SMB 在「成長、中性、價值」三種類型裡各自比較小型與大型，再取平均，所以 SMB 不太會受到價值效果的影響；HML 則在「小型、大型」裡各自比較價值與成長，所以 HML 不太會受到規模效果的影響。這就是為什麼要用雙變數排序，而不是各做一次單變數排序。

例題：手算某月的 SMB 與 HML

某月六個組合的市值加權報酬（%）：SG = 1.2、SN = 1.0、SV = 1.5、BG = 0.8、BN = 0.9、BV = 1.1。

  • SMB = (1.2 + 1.0 + 1.5) ÷ 3 − (0.8 + 0.9 + 1.1) ÷ 3 = 1.233 − 0.933 = 0.30%
  • HML = (1.5 + 1.1) ÷ 2 − (1.2 + 0.8) ÷ 2 = 1.30 − 1.00 = 0.30%

這個月小型股與價值股都表現較好，兩個因子皆為正。

6. 用 pandas 實作

以下程式採用「長格式」（每一列是一個股票-月份），全部用 groupby 完成，邏輯和第 2～5 節一一對應。假設已準備好兩個檔案：CRSP 月資料 crsp_monthly.csv，以及已算好 BM 的 compustat_bm.csv（每一列為 date、PERMNO、BM）。

步驟 1～2：讀取資料、計算市值、合併 BM

import numpy as np
import pandas as pd

crsp = pd.read_csv("crsp_monthly.csv", parse_dates=["date"])
crsp["date"] = crsp["date"] + pd.offsets.MonthEnd(0)      # 統一成月底日期
crsp = crsp[crsp["SHRCD"].isin([10, 11])]                  # 只保留普通股
crsp["RET"] = pd.to_numeric(crsp["RET"], errors="coerce")  # 處理 'C'、'B' 等非數值代碼
crsp["ME"] = crsp["PRC"].abs() * crsp["SHROUT"]            # 式 (3.1)

bm = pd.read_csv("compustat_bm.csv", parse_dates=["date"])
bm["date"] = bm["date"] + pd.offsets.MonthEnd(0)
df = crsp.merge(bm[["date", "PERMNO", "BM"]], on=["date", "PERMNO"], how="left")

# 權重要用「上個月底」的市值：先在完整資料上做 shift，避免前視偏誤
df = df.sort_values(["PERMNO", "date"])
df["ME_lag"] = df.groupby("PERMNO")["ME"].shift(1)

步驟 3：每年 6 月底，用 NYSE 股票計算分界點

june = df[(df["date"].dt.month == 6) & df["ME"].notna()].copy()
nyse = june[june["EXCHCD"] == 1]

me50 = nyse.groupby("date")["ME"].median().rename("me50")
bm_bp = (nyse[nyse["BM"] > 0]
         .groupby("date")["BM"].quantile([0.3, 0.7])
         .unstack()
         .rename(columns={0.3: "bm30", 0.7: "bm70"}))

june = june.join(me50, on="date").join(bm_bp, on="date")

步驟 4：貼上規模與價值標籤，形成 2×3 組合

june["size"] = np.where(june["ME"] <= june["me50"], "S", "B")
june["value"] = np.select(
    [june["BM"] < june["bm30"], june["BM"] <= june["bm70"]],
    ["G", "N"],
    default="V",
)
june = june[june["BM"] > 0]                    # BM 為負或缺值：不納入
june["port"] = june["size"] + june["value"]    # 例如 "SG"、"BV"
june["form_year"] = june["date"].dt.year

步驟 5：分組沿用到 7 月～隔年 6 月，計算市值加權報酬

# 7 月到 12 月屬於當年 6 月的分組；1 月到 6 月屬於前一年 6 月的分組
df["form_year"] = np.where(df["date"].dt.month >= 7,
                           df["date"].dt.year, df["date"].dt.year - 1)
held = df.merge(june[["PERMNO", "form_year", "port"]],
                on=["PERMNO", "form_year"], how="inner")
held = held.dropna(subset=["RET", "ME_lag"])

held["w_ret"] = held["RET"] * held["ME_lag"]
g = held.groupby(["date", "port"])[["w_ret", "ME_lag"]].sum()
ports = (g["w_ret"] / g["ME_lag"]).unstack("port") * 100   # 式 (3.3)，單位 %

步驟 6：組出 SMB 與 HML

smb = ports[["SG", "SN", "SV"]].mean(axis=1) - ports[["BG", "BN", "BV"]].mean(axis=1)  # 式 (3.4)
hml = ports[["SV", "BV"]].mean(axis=1) - ports[["SG", "BG"]].mean(axis=1)              # 式 (3.5)
factors = pd.DataFrame({"SMB_rep": smb, "HML_rep": hml})
補充：課堂版本的寫法

課堂範例把資料轉成「寬格式」（列 = 月份、欄 = PERMNO），用 ffill(limit=11) 把 6 月的分組往後延伸 11 個月，再 shift(1) 對齊下一期報酬。兩種寫法結果相同：寬格式比較直觀，長格式在股票數很多時比較省記憶體，也比較容易加入新的排序變數。

7. 驗證：和官方因子比一比

Kenneth French 的資料庫公布了官方的 FF3 因子與六個 2×3 投資組合報酬，可以用 pandas_datareader 直接下載比對：

import pandas_datareader.data as web

ff = web.DataReader("F-F_Research_Data_Factors", "famafrench",
                    start=factors.index.min(), end=factors.index.max())[0]
ff.index = ff.index.to_timestamp("M")          # 轉成月底日期，與 factors 對齊
compare = ff[["SMB", "HML"]].join(factors, how="inner")
print(compare.corr().round(3))

檢查重點：

  • 相關係數：課堂範例使用 2016～2020 年資料，複製的 SMB、HML 與官方因子的相關係數都在 0.98 左右，代表方法正確。
  • 逐組比較：若某個因子對不上，可以下載官方的 6_Portfolios_2x3，逐一比較 SV、BG 等組合，找出是哪一組出問題。
  • 剩下的小差異從哪來？官方 BM 的時間點定義更嚴格（帳面權益來自 t−1 會計年度、除以 t−1 年 12 月底市值），且帳面權益會加上遞延稅、扣掉特別股，同一家公司的多種股票市值也會合併計算。

8. 做出來之後：FF3 迴歸怎麼用？

有了三個因子，就可以對任何股票或基金做時間序列迴歸，看它的報酬來自哪裡：

Ri,t − Rf,t = αi + βi(Mkt-RF)t + siSMBt + hiHMLt + εi,t 式 (3.6)　FF3 時間序列迴歸
表 3.3　如何解讀迴歸係數
係數大於 0小於 0
si（SMB 負荷）偏向小型股偏向大型股
hi（HML 負荷）偏向價值股偏向成長股
αi三個因子都解釋不了的平均超額報酬；顯著為正才代表真正的「超額」表現
延伸：如果要做台灣版的 FF3？

流程完全相同，只要替換資料與分界點：股價、市值與財報資料可以使用 TEJ 台灣經濟新報；分界點可以改用上市（TWSE）股票計算，角色類似美國的 NYSE；無風險利率可用一年期定存利率或短期票券利率換算的月利率。台灣上市公司的年度財報須在會計年度結束後三個月內公告，因此「6 月底排序」的時間點同樣能避免前視偏誤。

重點整理

  • ME = |PRC| × SHROUT；股價取絕對值，是因為 CRSP 用負號標記以買賣價平均代替收盤價的情況。
  • 只用普通股（SHRCD 10、11），但分界點只用 NYSE 股票（EXCHCD = 1）計算，以免被微型股主導。
  • 每年 6 月底排序，持有到隔年 6 月；BM 使用前一年的財報資訊，權重使用上個月底的市值，避免前視偏誤。
  • 規模以 NYSE 中位數分兩組，BM 以 NYSE 第 30、70 百分位分三組，交集成六個市值加權組合。
  • SMB ＝ 三個小型組合平均 − 三個大型組合平均；HML ＝ 兩個價值組合平均 − 兩個成長組合平均。
  • 複製結果應與 Kenneth French 官方因子高度相關（約 0.98）；對不上時，逐組比較六個投資組合找出問題。

小練習

Q1.某月六個組合的報酬（%）為：SG = −2.0、SN = 0.5、SV = 1.0、BG = 3.0、BN = 1.0、BV = −0.5。請計算 SMB 與 HML，並用一句話描述這個月的市場風格。

查看解答

SMB = (−2.0 + 0.5 + 1.0) ÷ 3 − (3.0 + 1.0 − 0.5) ÷ 3 = (−0.167) − 1.167 = −1.33%。

HML = (1.0 − 0.5) ÷ 2 − (−2.0 + 3.0) ÷ 2 = 0.25 − 0.50 = −0.25%。

這個月大型股明顯勝過小型股，成長股也略勝價值股，主要是大型成長股（BG = 3.0%）帶動。

Q2.同學在計算組合報酬時，用的是「當月底」的市值 MEt 作為權重，而不是 MEt−1。這會造成什麼問題？

查看解答

這是前視偏誤。當月底的市值已經包含當月的漲跌：當月大漲的股票，MEt 會變大，權重也跟著變大。等於事後才加碼贏家，組合報酬會被系統性高估。正確做法是用月初（上個月底）就已知的 MEt−1，對應程式中的 groupby("PERMNO")["ME"].shift(1)。

Q3.某檔基金對 FF3 跑迴歸，得到 α = 0.05%（t = 0.4）、β = 1.02、s = 0.65、h = −0.30。這檔基金的投資風格為何？經理人有沒有選股能力？

查看解答

市場 β 約為 1，s = 0.65 > 0 表示偏向小型股，h = −0.30 < 0 表示偏向成長股：這是一檔小型成長型基金。

α 的 t 值只有 0.4，遠小於 1.96，統計上不顯著。基金的報酬可以被市場、規模與價值三個因子解釋，沒有證據顯示經理人有額外的選股能力。
