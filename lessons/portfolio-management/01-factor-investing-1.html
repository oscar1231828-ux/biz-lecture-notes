1. 什麼是因子投資？

傳統選股是一檔一檔研究公司，再憑判斷決定買賣。因子投資（factor investing）則反過來：先找出「哪些證券特性長期伴隨較高報酬」，再用明確的規則，把所有具有這種特性的股票一次買進（或放空）。

定義：因子投資

以證券的某些屬性（attributes）為依據形成投資策略，而這些屬性在歷史上與較高的報酬有關。策略的規則事先寫好、可以被重複執行與回測。

常見的因子大致可以分成四類：

表 1.1　因子的四種類型
類型使用的資訊例子
基本面風格因子財務報表等會計資訊帳面市值比、獲利能力、投資率
統計（技術面）風格因子價格與成交量動能、波動度、流動性（見第 02 講）
總體經濟因子景氣與通膨等總體變數工業生產成長率、通膨意外
ESG 因子環境、社會、公司治理評分ESG 評等分數

業界常把因子投資稱為智慧型貝他（smart beta）。它可以是被動的（例如追蹤價值因子指數的 ETF），也可以是主動的（經理人自行決定因子權重）。與傳統選股相比，規則式的因子投資更透明、更有系統：同樣的規則、同樣的資料，任何人都能得到同樣的投資組合。

2. 特徵與因子：兩個容易混淆的概念

「小型股報酬比較高」這句話其實可以從兩個角度理解，對應到兩種不同的實證方法。

特徵（Characteristics）：屬於個別公司

特徵是個別公司的屬性，例如某公司的 β、市值（ME）、帳面市值比（BM）。特徵本身不能拿來交易，可以把它想成「這家公司對某種風險溢酬的暴露程度」。研究特徵時，用的是橫斷面迴歸（cross-sectional regression）：在同一時間點，用所有股票的特徵去解釋它們的報酬差異。

Ri = BMi λ̂BM + MEi λ̂ME + εi 式 (1.1)　橫斷面迴歸：同一期、不同股票

因子（Factors）：所有資產共用

因子是所有資產共同面對的系統性風險來源，例如「整體市場」或「小型股相對大型股的表現」。我們希望不同因子之間盡量互不相關（orthogonal），各自代表一種獨立的風險溢酬。研究因子時，用的是時間序列迴歸（time-series regression）：針對一檔股票，用它過去每一期的報酬去迴歸因子報酬，得到它對因子的暴露 β̂i。

Ri,t = β̂i RPt + εi,t 式 (1.2)　時間序列迴歸：同一股票、不同時期
  • λ̂：每單位特徵所對應的報酬（橫斷面估計的風險溢酬）
  • RPt：第 t 期的因子報酬（風險溢酬）
  • β̂i：股票 i 對該因子的負荷（loading）

可交易與不可交易因子

可交易因子（tradable）不可交易因子（non-tradable）
本質由可交易資產組成的投資組合影響整體市場的總體變數
例子市場因子、規模因子、價值因子、動能因子GDP、工業生產、就業率、投資人情緒

3. 建構因子的五個步驟

不論是哪一種因子，建構流程都可以拆成同樣的五步。後面介紹的所有因子，包括第 03 講要親手實作的 SMB 與 HML，都是照這個流程做出來的。

  1. 找出交易訊號：決定要用哪個屬性排序，例如市值、帳面市值比，並把它計算出來。
  2. 分組：依訊號把資產分進不同的投資組合（例如高、中、低三組）。
  3. 決定權重：組合內每檔資產要放多少錢，常見的是等權重或市值加權（第 4 節）。
  4. 定期再平衡：訊號會隨時間改變，要定期重新排序、重新分組，並維持設定的權重。
  5. 回測：計算投資組合的歷史報酬，評估表現。

橫斷面策略：買高、空低

如果資產的預期報酬會隨某個屬性單調遞增，就可以在每一期依該屬性把資產排序，買進排名高的、放空排名低的，形成一個多空投資組合（long-short portfolio）。這就是橫斷面策略（cross-sectional strategy, CS）：

RCS,t = RHigh,t − RLow,t 式 (1.3)　橫斷面策略的因子報酬

多空組合的好處是：市場整體漲跌對多頭和空頭的影響大致互相抵銷，剩下的報酬比較「純粹」地反映這個屬性帶來的溢酬。

4. 排序方法：單變數與雙變數

單變數排序（univariate sort）

每一期依單一屬性，在所有資產中找出分界點（breakpoints），把資產分組。例如用當期所有股票市值的中位數，把股票分成小型股與大型股。常見的分法：

表 1.3　常見的分界方式
分法比例組數
中位數（median）50 / 502
三分位（tertiles）30 / 40 / 303
五分位（quintiles）20 / 20 / 20 / 20 / 205
十分位（deciles）10 / … / 1010

非條件雙變數排序（unconditional bivariate sort）

實務上常常要同時考慮兩個訊號。非條件排序的做法是：對屬性 X 與屬性 Y 各自獨立做一次單變數排序，再取兩者的交集。以 3×3 為例，會得到 9 個投資組合：

表 1.4　3×3 非條件雙變數排序
排序Y1Y2Y3
X1X1, Y1X1, Y2X1, Y3
X2X2, Y1X2, Y2X2, Y3
X3X3, Y1X3, Y2X3, Y3

因為兩次排序互相獨立，先排哪個都一樣；但若 X 與 Y 相關（例如小型股的 BM 往往較高），有些格子的股票會特別多、有些特別少。

條件雙變數排序（conditional bivariate sort）

條件排序是「先排一次、再在每一組裡面排第二次」：第二次排序只在第一次選出的資產中進行。

表 1.5　非條件排序 vs. 條件排序
非條件排序條件排序
每組股票數可能不平均大致相同
排序先後不影響結果會影響結果
主要缺點屬性相關時，部分格子股票太少第一次排序後，組內第二個屬性的差異（dispersion）可能不夠大

5. 投資組合的加權方式

等權重（equal-weighted, EW）

組合裡有 N 檔資產，每檔權重都是 1/N，等於每檔投入一樣多的錢：

REW,t = 1N ∑i=1N Ri,t 式 (1.4)　等權重投資組合報酬

等權重組合每一期都必須再平衡：漲多的股票權重會變大，要賣掉一些、補進跌的股票。此外，相對於市場，它等於加碼小型股、減碼大型股。

市值加權（value-weighted, VW）

每檔資產的權重與它在建立組合時（上一期末）的市值成正比：

RVW,t = ∑i=1N MEi,t−1 Ri,t∑j=1N MEj,t−1 ，　MEi,t−1 = Pricei,t−1 × Sharesi,t−1 式 (1.5)　市值加權投資組合報酬

只要組合的成分股不變，市值加權組合會自動維持權重（股價漲了，市值與權重本來就一起變大），因此交易成本遠低於等權重組合。

例題：同樣三檔股票，兩種權重差多少？

上個月底市值：A = 600 億、B = 300 億、C = 100 億；本月報酬：A = +2%、B = +5%、C = −10%。

  • 等權重：(2% + 5% − 10%) ÷ 3 = −1.0%
  • 市值加權：權重分別為 0.6、0.3、0.1，報酬 = 0.6×2% + 0.3×5% + 0.1×(−10%) = 1.2% + 1.5% − 1.0% = +1.7%

差距來自 C：它是最小的公司，卻在等權重組合中拿到和 A 一樣的 1/3 權重。這就是「等權重＝加碼小型股」的具體意思。

6. 學術界的因子模型

Chen-Roll-Ross 總體經濟因子模型（1986）

CRR 模型用五個總體經濟變數解釋股票報酬：

Ri,t = αi + bi,MPMPt + bi,DEIDEIt + bi,UIUIt + bi,UPRUPRt + bi,UTSUTSt + εi,t 式 (1.6)　Chen-Roll-Ross 模型
  • MP：工業生產成長率　DEI：預期通膨的變動　UI：非預期通膨（三者皆不可交易）
  • UPR：違約溢酬，BAA 與 AAA 公司債殖利率差　UTS：期限溢酬，20 年期與 1 年期公債殖利率差（兩者可用債券多空組合交易）

不可交易的因子沒辦法直接買賣，所以要建立因子模擬投資組合（factor mimicking portfolio）：把總體因子對一組可交易的基礎資產 B（例如依規模與 BM 排序的投資組合）做迴歸，用估計出來的權重組成一個「長得最像」該因子的組合。

MPt = μ + w′Bt + θt　⟹　M̂Pt = ŵ′Bt 式 (1.7)　以迴歸權重建立 MP 的模擬投資組合

Fama-French 三因子模型（FF3, 1993）

Ri,t = αi + βi,Mkt-RFRMkt-RF,t + βi,SMBRSMB,t + βi,HMLRHML,t + εi,t 式 (1.8)　Fama-French 三因子模型
  • RMkt-RF：市場風險溢酬，市場投資組合的超額報酬
  • RSMB（small minus big）：規模溢酬，買小型股、空大型股
  • RHML（high minus low）：價值溢酬，買高 BM 的價值股、空低 BM 的成長股

SMB 與 HML 都是由市值（ME）與帳面市值比（BM）的 2×3 非條件雙變數排序建構而成：

表 1.6　FF3 的六個投資組合
成長 Growth（BM 低 30%）中性 Neutral（中間 40%）價值 Value（BM 高 30%）
小 Small（ME ≤ 中位數）SGSNSV
大 Big（ME > 中位數）BGBNBV
  • 分界點只用 NYSE 股票計算：ME 用 NYSE 中位數；BM 用 NYSE 的第 30 與第 70 百分位數。
  • 六個組合都採市值加權。
  • SMB ＝ 三個小型組合的平均 − 三個大型組合的平均；HML ＝ 兩個價值組合的平均 − 兩個成長組合的平均。
  • 這種「在另一個維度上平均」的設計，可以降低 SMB 與 HML 之間的相關性。完整的計算與程式實作見第 03 講。

Fama-French 五因子模型（FF5, 2015）與 q 因子模型（HXZ, 2015）

後續研究發現，獲利能力與投資率也能解釋報酬差異，於是出現了更多因子的模型：

表 1.7　主要的基本面因子模型比較
模型市場規模價值獲利能力投資
FF3（1993）Mkt-RFSMBHML——
FF5（2015）Mkt-RFSMBHMLRMW：營業獲利（扣除利息費用）高者減低者CMA：總資產成長率低者減高者

FF5 的新因子建構方式和 FF3 一樣：用 ME 與 OP（或 Inv）做 2×3 排序，分界點同樣取 NYSE 的中位數與第 30、70 百分位。名稱裡的 R/W 是 robust/weak（獲利穩健／疲弱），C/A 是 conservative/aggressive（投資保守／積極）。

補充：為什麼「低投資」的公司報酬比較高？

q 因子理論的直覺是：公司會在資金成本（也就是投資人要求的報酬）低的時候擴大投資。所以大舉投資的公司，往往是預期報酬已經偏低的公司；反之，保守投資的公司預期報酬較高。

7. 因子動物園與可複製性

學術界發表的因子數量持續暴增。Harvey 與 Liu 統計頂尖期刊上已有超過 400 個因子，並指出其中有許多可能只是資料探勘下的「幸運發現」。業者常引用這些回測結果來推銷產品，結果讓投資人對實際績效抱持過高期待。這個現象被戲稱為因子動物園（factor zoo）。

Hou、Xue 與 Zhang（2020）重新檢驗了 452 個異常報酬。在使用 NYSE 分界點、市值加權以降低微型股影響後：

  • 約 65% 的異常報酬，連最基本的 |t| ≥ 1.96 門檻都過不了；
  • 若考慮多重檢定、把門檻提高到 2.78，失敗比例上升到約 82%；
  • 就算是能複製的異常報酬，經濟規模通常也比原始論文報告的小很多。
常見錯誤：只看回測就相信一個因子

評估因子時，至少要問：用的是等權重還是市值加權？分界點是否被微型股主導？t 值有沒有考慮多重檢定？樣本外（out-of-sample）是否依然有效？

ESG 因子的資料問題

ESG 是高度異質的領域，評等機構在投資流程中扮演關鍵角色。但 Li 與 Polychronopoulos（2020）指出，不同評等機構的方法並不一致，換一家評等機構，建構出來的投資組合就可能大不相同。缺乏穩健的資料，是 ESG 策略普及的一大障礙。

重點整理

  • 因子投資是用明確規則，依證券屬性建立投資組合；它比傳統選股更透明、可重複，業界稱為 smart beta。
  • 特徵屬於個別公司，用橫斷面迴歸研究；因子是所有資產共用的風險來源，用時間序列迴歸估計負荷。
  • 建構因子五步驟：找訊號 → 分組 → 決定權重 → 再平衡 → 回測。橫斷面因子報酬＝高組報酬 − 低組報酬。
  • 非條件雙變數排序先後不影響結果，但各組股數可能不均；條件排序各組股數相近，但排序先後會影響結果。
  • 等權重組合隱含加碼小型股，且每期都要再平衡；市值加權組合會自動維持權重、成本較低。
  • FF3 的 SMB 與 HML 來自 ME × BM 的 2×3 排序，分界點用 NYSE 股票計算，六個組合皆市值加權。
  • FF5 加入獲利能力（RMW）與投資（CMA）；HXZ q 因子模型使用 ROE 與 I/A。
  • 大多數已發表的異常報酬在嚴格檢驗下無法複製，評估因子時要注意加權方式、微型股與多重檢定。

小練習

Q1.某投資組合有三檔股票。上月底市值：X = 200、Y = 50、Z = 750（億元）；本月報酬：X = +4%、Y = +12%、Z = −2%。請分別計算等權重與市值加權的報酬。

查看解答

等權重：(4% + 12% − 2%) ÷ 3 = 14% ÷ 3 ≈ 4.67%。

市值加權：總市值 1,000，權重為 0.2、0.05、0.75。報酬 = 0.2×4% + 0.05×12% + 0.75×(−2%) = 0.8% + 0.6% − 1.5% = −0.1%。

表現最好的 Y 是最小的公司，在等權重中占 1/3，在市值加權中只占 5%，所以兩者差異很大。

Q2.請判斷下列因子屬於可交易或不可交易：(a) 價值因子 HML　(b) 消費者信心指數　(c) 期限溢酬 UTS　(d) 非預期通膨 UI。對於不可交易的因子，要怎麼做才能用它來交易？

查看解答

(a) 可交易：本身就是股票多空組合。(b) 不可交易：總體／情緒變數。(c) 可交易：可以用長短期公債的多空組合實現。(d) 不可交易：總體變數。

不可交易因子可以建立因子模擬投資組合：把因子對一組可交易的基礎資產（例如規模與 BM 排序的投資組合）做迴歸，再用估計出的權重 ŵ 組成投資組合，見式 (1.7)。

Q3.研究者想同時依「市值」與「帳面市值比」分組。已知小型股的 BM 普遍較高。如果使用非條件 3×3 排序，可能會遇到什麼問題？改用條件排序（先排市值、再在各市值組內排 BM）又會有什麼代價？

查看解答

非條件排序：因為兩個屬性正相關，「大型＋高 BM」或「小型＋低 BM」的格子裡股票會很少，這些組合的報酬容易被少數股票主導、雜訊很大。

條件排序：每組股數會大致相同，但(1)排序先後會影響結果，(2)在某個市值組內，BM 的差異可能不夠大，高 BM 組與低 BM 組的差距被壓縮，得到的價值溢酬可能偏小。
